# Проверка Crowdly 0.2.1

Дата: 16 ноября 2026 года. Исходный commit: `ec9cc3f23eab19332cd92fd12538c13253c37a3a`. Проверки относятся к реализации, а не к точности прогноза реального спроса.

## Автоматические проверки

`npm run check` запускает 62 теста и production-сборку Vite. Проверены:

- ручные эталоны маржи, безубыточности, допустимой аренды, помесячного потока, окупаемости, NPV и IRR;
- период выхода на загрузку и дополнительный резерв для первых убыточных месяцев;
- нулевые наблюдения, отрицательная маржа, невозможная безубыточность, ограничение мощности, рост цен и затрат;
- распределение спроса, календарная мощность, каннибализация и разница налогов сети;
- границы модели, JSON round-trip, повреждённые данные, неизвестные поля, дубликаты, ограничение UTF-8 размера;
- ошибка localStorage и квоты без уничтожения предыдущей записи;
- все стартовые форматы на RU/EN в рублях; отказ при другой валюте; сохранение исходных копий без переименования сумм;
- автономная HTML-сборка: сохранение специальных символов JS/CSS и безопасное встраивание закрывающих script-тегов;
- CSV-экранирование, UTF-8 BOM и защита строк от формул при открытии в таблицах;
- регрессия старого импорта tenantShares и React render отчёта с повреждёнными заметками.

Тесты используют синтетические и ручные эталонные данные. Обучения и независимой проверки спроса на клиентах не проводилось.

## Браузерная проверка рублёвого обновления 0.2.1

- На лендинге и в форме нет выбора валюты; отображается только RUB.
- Новый расчёт использует российские учебные значения: билет 1 400 ₽, аренда 600 000 ₽, вложения 8 млн ₽.
- Переключение результата на EN сохраняет RUB и те же показатели: 48 визитов/день, 693 000 ₽ операционного результата, 14,7 месяца окупаемости.
- Новое пространство в расширенном режиме предлагает только «Российские рубли · RUB» в неизменяемом поле.
- Реальная локальная копия предыдущего теста содержала валютные записи. При открытии показана защита исходника; продолжение отключено до скачивания. Исходная JSON-копия успешно скачана, затем отдельная кнопка разрешила рублёвое сохранение.
- Валютные импорты и сохранение старых исходников дополнительно покрыты регрессионными тестами.

## Границы браузерной проверки

- Импорт через файловый диалог остановлен механизмом разрешений облачного браузера: доступ к загрузке тестового JSON не был предоставлен. Обходов не выполнялось. Парсер, восстановление и повреждённые копии покрыты автоматическими тестами; UI-импорт нельзя считать пройденным E2E.
- Печать использует штатное окно браузера. Раздел отчёта реализован, но сохранение PDF через системный диалог отдельно не проверено.
- Crowdly_Trial.html собирается из той же production-сборки, без внешних JS/CSS. Открытие file:// не разрешено облачным браузером, поэтому прямой запуск автономного файла не заявляется как браузерный тест. HTML-структура и синтаксис встроенного JS проверяются отдельно.
- Мобильная проверка проведена в узком iframe, не на физическом iOS/Android устройстве.

## GitHub и публикация

Чтение и клонирование Wo1gmi/Crowdly успешны. Пробный push новой ветки остановился из-за отсутствия GitHub credentials. Исходный репозиторий не изменён. Проверки GitHub Actions в этой сессии не запускались. Изменения подготовлены в ветке codex/crowdly-acceleration, с отдельной публикацией через Sites и переносимым исходным архивом.

## Перед обещанием точности прогноза

Нужны реальные данные сопоставимых объектов, целиком отложенные площадки и периоды, сравнение с сезонным наивным прогнозом и разбор ошибок. Для многопользовательской подписки нужны серверное хранение, аутентификация, доступы и коммерческие процессы. Сейчас работает локальный сценарный продукт; эти возможности не имитируются.

## Пользовательские сценарии

1. Открыть демонстрационный проект → изменить цену/вместимость в симуляторе → увидеть пересчёт → сохранить сценарий → сравнить с исходным.
2. Создать проект → ввести объекты/конкурентов и группы аудитории → задать параметры затрат/сезонности → получить расчёт и отчёт.
3. Экспортировать ID объектов → заполнить CSV истории → загрузить и просмотреть → подтвердить импорт → оценить масштаб спроса.
4. Выбрать арендную модель → задать категории, доли, ставки и занятость → сравнить составы пространства.
5. Скачать JSON-копию → восстановить в другом браузере → продолжить расчёты.

## Технические границы

Статический frontend без backend/секретов/внешних API. До 50 проектов, 100 объектов/групп/сценариев на проект, 50 000 строк истории. Это защитные пределы импорта, не обещание мгновенного интерфейса при максимальном размере. Для большого объёма нужны worker и backend. LocalStorage имеет браузерную квоту; ошибка сохранения отображается явно.

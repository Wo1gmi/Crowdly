Версия 0.2.1 · 16 ноября 2026 · Только российские рубли (RUB)

С ЧЕГО НАЧАТЬ
Распакуйте весь архив. Для знакомства с продуктом откройте product/Crowdly_Trial.html в Chrome, Edge или другом современном браузере. Нажмите «Рассчитать мой бизнес» и замените учебные вводные своими. Установка, регистрация и API-ключи для расчёта не нужны. Если хотите сначала увидеть готовый пример, нажмите «Открыть пример».

Все цены, вводные и денежные результаты в продукте, презентации и Excel — в рублях. Смена языка RU/EN валюту не меняет.

ЧТО ВНУТРИ
product/ — автономный HTML и инструкции на русском и английском. Эти три файла можно отдельно переслать клиенту.
presentation/ — презентация на 17 слайдов: редактируемый PowerPoint, PDF и программный исходник сборки. Для редактирования используйте PPTX; ограничения запуска программного исходника указаны в SOURCE_NOTES_RU.txt.
business/ — Crowdly_Business_Model.xlsx и руководство BUSINESS_MODEL_RU.md. Это экономика самого стартапа Crowdly; экономика клиентской точки рассчитывается в продукте.
source/Crowdly/ — полный исходный код проекта с lock-файлом, тестами, документацией и настройками публикации. Зависимости node_modules устанавливаются командой npm ci.
source/Crowdly_Acceleration.patch — два коммита изменений относительно исходного GitHub.
docs/ — аудит исходного продукта и презентации, выполненные итерации, методика, ограничения, исследование рынка, стратегия и программа пилотов.
RELEASE.json — версия, исходный commit, результат проверок и контрольные суммы файлов.

ЗАПУСК ДЛЯ РАЗРАБОТЧИКА
Нужен Node.js 20.19.x либо 22.12+ и npm. В терминале перейдите в source/Crowdly/ и выполните:

npm ci
npm run dev

Откройте адрес, который выведет Vite (обычно http://127.0.0.1:5173).

npm run check          — автоматические тесты и production-сборка
npm run build          — статическая веб-сборка в dist/
npm run preview        — просмотр собранного сайта
npm run build:portable — автономный release/Crowdly_Trial.html

В готовый product/Crowdly_Trial.html уже встроены код и стили. Интернет нужен для первоначальной установки зависимостей из исходников, но не для основных расчётов в готовом файле. Backend для расчётов не требуется.

БИЗНЕС-МОДЕЛЬ И БЛИЖАЙШАЯ ПРОВЕРКА
Начальная гипотеза: операторы платного досуга, выбирающие новую точку. Самостоятельный бесплатный расчёт ведёт к сопровождаемому пилоту на 4–6 недель; гипотеза цены — 150 000 ₽. Подписка 25 000 ₽ в месяц рассматривается после подтверждения повторных задач и реализации совместной работы.

В Excel пять вкладок. «Гипотезы»!E5 переключает сценарии 1/2/3. Цены, продажи и будущая подписка — допущения, которые нужно проверить. Предложенный капитал 20 млн ₽: программа на 12 месяцев 17,2 млн ₽ и резерв 2,8 млн ₽. Это бюджетный сценарий, а не подтверждённый факт привлечения денег.

Цели ближайшей программы: 20 интервью, 5 партнёров разработки, 10 самостоятельных расчётов своего бизнеса, 3 оплаченных пилота и 2 повторных решения. Клиенты и продажи не выдуманы: перечисленное является целями, а не существующим traction.

# Crowdly

**Проверьте экономику новой точки до подписания аренды.**

Рабочая beta для России и ОАЭ: отдельный лендинг, самостоятельный расчёт на своих вводных, сценарии, чувствительность, сохранение вариантов и отчёт. Основной путь доступен на русском и английском. **Все денежные значения и расчёты — только в российских рублях (RUB).** Выбора валюты нет.

## Быстрый запуск

Node.js 20.19+ или 22+.

```sh
npm ci
npm run dev
```

```sh
npm run check          # тесты расчётов, хранения, импорта/экспорта + production build
npm run build          # статическая сборка в dist
npm run build:portable # автономный release/Crowdly_Trial.html
```

Автономный HTML содержит приложение и стили в одном файле, без CDN и серверного API. Его можно передать клиенту для открытия в современном браузере. Если конкретный браузер запрещает LocalStorage для локальных файлов, расчёт работает в памяти, а для сохранения доступен JSON.

## Клиентский путь

1. Лендинг объясняет решение, методику, ограничения и содержит крупную кнопку запуска в середине страницы.
2. Клиент выбирает формат: семейный центр, wellness/термы, кафе или свой формат.
3. Изменяет известные ему значения: чек, мощность, аренду, затраты и вложения. Все поля имеют редактируемые учебные значения.
4. Получает необходимое число посещений в день, предельную аренду, денежные потоки, NPV/IRR и срок возврата вложений.
5. Сравнивает поток −30% / базовый / +30%, меняет загрузку, сохраняет варианты, скачивает CSV/JSON или печатает отчёт в PDF.

Свои наблюдения посещений можно ввести одним необязательным полем. Чужая посещаемость, API-ключи, регистрация и внешние данные для первого результата не нужны.

## Что означают цифры

Это **сценарная модель экономики**, а не подтверждённый прогноз спроса по адресу. Учебные значения не являются рыночными средними. Город служит подписью проекта. Данные пользователя, допущения и вычисленные показатели обозначены отдельно.

Сценарии ±30% не являются доверительными интервалами. Изменение цены в чувствительности не подразумевает известную эластичность. Налог — условный параметр, не реализация налогового законодательства. Модель не учитывает долг, амортизацию, НДС, отдельный депозит, полный оборотный капитал или остаточную стоимость. Денежные убытки в период запуска включаются в потребность в финансировании.

Пример семейного центра в RUB: билет 1 400, переменные затраты 25%, аренда 600 000, остальные постоянные затраты 912 000, 30 рабочих дней, мощность 200 визитов/день, плановая загрузка 35%. Результат: **48 визитов/день до операционной безубыточности**, базовые 70 визитов/день, 693 000 RUB операционной прибыли в стабильный месяц. Это учебный пример, не наблюдения клиента.

## Маршруты

| URL-фрагмент | Раздел |
|---|---|
| без фрагмента | Лендинг |
| `#start` | Новый расчёт |
| `#planner` | Последний расчёт |
| `#demo` | Учебный пример |
| `#dashboard` | Расширенное рабочее пространство сети, интерфейс RU |

Hash-навигация работает на статическом хостинге. `base: './'` поддерживает размещение в подкаталоге, включая GitHub Pages.

## Расширенная модель сети

Исходное приложение сохранено как отдельный расширенный режим: объекты сети, конкуренты, группы аудитории, сценарии, каннибализация, состав пространства, калибровка одного масштаба по истории и импорт CSV. Это исследовательский режим на заданных коэффициентах. Его наличие не доказывает точность прогнозирования реального спроса.

В ходе аудита исправлены расчёт потока при выходе на загрузку, календарная мощность, налоговый эффект сети, финансовая валидация и диагностика непригодной истории.

## Данные и перенос

- Основной расчёт хранится в `crowdly.planner.v2`, расширенное пространство — в отдельном `crowdly.workspace.v1`.
- Проекты не отправляются на сервер. Приложение не содержит трекеров, секретов или платных API.
- JSON включает вводные, их происхождение и сохранённые варианты. При восстановлении действующий проект автоматически сохраняется среди вариантов.
- Повреждённая исходная запись не перезаписывается автоматически; доступно скачивание исходного текста.
- CSV содержит все три сценария, месячные потоки и исходные предпосылки. Текст, похожий на формулы Excel, нейтрализуется, отрицательные финансовые числа остаются числами.

## Публикация и репозиторий

Исходный репозиторий: https://github.com/Wo1gmi/Crowdly . Работа ведётся в отдельной ветке `codex/crowdly-acceleration`. Чтение исходного GitHub подтверждено, push требует авторизованного доступа на запись. Наличие локальной ветки не означает, что она опубликована в исходном репозитории.

Существующий workflow GitHub Pages собирает `dist` после push в `main`, когда Pages включён в настройках репозитория. Для Sites используется `.openai/hosting.json`. Сайт и автономный файл не требуют backend для расчётов.

Клиентские аккаунты, совместная работа, оплата, интеграции с CRM и подтверждённая модель локального спроса относятся к следующему этапу. План их проверки и критерии перехода описаны в стратегии; текущая beta не имитирует эти возможности.

## Обновление 0.2.1: только рубли

По уточнению владельца убраны валютные переключатели и нерублёвые примеры из лендинга, планировщика, расширенного режима и материалов. Английский интерфейс также считает в рублях. Старые проекты в другой валюте не переименовываются и не пересчитываются автоматически: исходная JSON-копия доступна для скачивания, а сохранение рублёвой версии включается отдельной кнопкой после скачивания копии. Импорт нового файла с нерублёвыми суммами отклоняется без изменения файла.
